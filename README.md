# Train Food — Python нұсқасы

Бұл жоба Node.js/Vue қолданбайды. Негізгі логика Python тілінде жазылған.

## Технологиялар

- Python 3.12+
- FastAPI
- Jinja2
- SQLAlchemy
- SQLite (әдепкіде)
- PostgreSQL-ге ауыстыруға болады
- WebSocket

## Іске қосу

```bash
python -m venv .venv
```

Windows:

```bash
.venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

Ашу:

- Жолаушы: http://127.0.0.1:8000/
- Кухня: http://127.0.0.1:8000/kitchen
- API: http://127.0.0.1:8000/docs

## WhatsApp: тапсырыс әр пойыздың аспазына барады

- Әр пойыздың өз аспазы бар: `/admin/trains` бетінде пойыздың карточкасындағы **«Аспаз / WhatsApp өзгерту»** батырмасы арқылы аспаздың аты мен WhatsApp нөмірін енгізіңіз (мысалы `+7 707 123 45 67`).
- Жолаушы тапсырыс бергенде, тапсырыс базаға сақталады (аспаз панелі `/kitchen` және күйін бақылау жұмыс істей береді) да, **WhatsApp ашылады**: хабарлама (пойыз, вагон, орын, тағамдар, сома) дайын жазылып тұрады — жолаушы «Жіберу» батырмасын басады. Бет қайта ашылса, `/order/...` бетіндегі жасыл WhatsApp батырмасымен қайта жіберуге болады.
- Нөмір көрсетілмеген пойыз үшін ортақ нөмір қолданылады: `WHATSAPP_DEFAULT_PHONE` айнымалысы немесе `system_settings` кестесіндегі `whatsapp_default_phone`. Ол да жоқ болса, WhatsApp батырмасы шықпайды (тапсырыс кухня панеліне барады).
- Жолаушының пойызы (QR арқылы) cookie-де 24 сағат сақталады, сондықтан `/menu` мен `/lunchboxes` арасында ауысқанда пойыз ұмытылмайды.

## Мәзір және ланчбокс

- `/menu` — жалпы тағамдар мен сусындар. Ланчбокс санаты мұнда көрсетілмейді.
- `/lunchboxes` — ланчбокстар жеке бетте. Әдепкі бағасы — **3500 ₸** (үшеуіне де); оны `/admin/menu` арқылы өзгертуге болады (бағасы 0 болса, ланчбокс «қолжетімсіз» болып тұрады).
- **Ланчбокс — тек алдын ала тапсырыс (предзаказ).** Ол билет сатып алғанда беріледі және пойыз жүруіне кемінде **24 сағат** қалғанда ғана қабылданады; пойыздың ішінде ланчбокс тапсырыс беруге болмайды. Жолаушы `/lunchboxes` бетінде пойызды, жүру күні мен уақытын (Қазақстан уақыты, UTC+5), аты мен телефонын көрсетеді; вагон/орын — міндетті емес. Ланчбокс себеті жалпы мәзір себетінен бөлек, ланчбокс пен мәзір тағамын бір тапсырыста араластыруға болмайды.
- Тексеру сервер жағында да жасалады (`POST /api/orders`). Минимал мерзімді `system_settings` кестесіндегі `lunchbox_min_advance_hours` (әдепкі `24`) арқылы өзгертуге болады.
- Аспаз панелінде (`/kitchen`) және WhatsApp хабарламасында предзаказ «🍱 ПРЕДЗАКАЗ» белгісімен және жүру уақытымен көрсетіледі. Предзаказға «тапсырыс қабылдауды тоқтату» (CLOSED) режимі әсер етпейді.

## Тегін хостингке орналастыру (тестілеу үшін, Render)

1. Репозиторийді GitHub-қа жүктеңіз (`render.yaml` файлы дайын).
2. render.com → **New → Blueprint** → GitHub репозиторийін таңдаңыз.
3. Render сұрайтын `ADMIN_PASSWORD`, `KITCHEN_PASSWORD`, `STAFF_PASSWORD` мәндерін өзіңіз енгізіңіз.
4. Deploy біткен соң сайт `https://dar-res-train-food.onrender.com` сияқты сілтемеде ашылады.

Тегін жоспар тек тестілеуге арналған: сайт біраз уақыт қолданылмаса "ұйықтап" қалады (бірінші ашылу ұзақ), ал SQLite базасы мен админ арқылы жүктелген суреттер қайта қосылғанда өшеді. Тұрақты дерек үшін `DATABASE_URL` арқылы сыртқы PostgreSQL қосыңыз.
